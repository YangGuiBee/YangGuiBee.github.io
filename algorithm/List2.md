[2.4.3.09] 결정경계 시각화 (Decision Boundary Plot)


[3] 강화학습
[3.1] Model-free RL : Value based methods
[3.1.01] Q-Learning: 상태 공간에서 사용되는 표(Q-Table) 기반
[3.1.02] SARSA(State Action Reward State Action)
[3.1.03] Q-Network: 신경망을 사용하여 Q-값을 근사화하는 모델
[3.1.04] DQN(Deep Q-Network): 딥러닝을 활용한 Q-Learning의 발전된 형태
[3.1.05] Double DQN: Q-Learning의 과대 평가 문제를 완화하기 위한 개선된 버전
[3.1.06] Dueling DQN: 상태 가치와 행동의 중요도를 분리하여 Q-값을 계산하는 모델
[3.1.07] DRQN(Deep Recurrent Q-Network): 순차적인 경험을 학습하기 위해 RNN 구조를 포함한 DQN
[3.1.08] C51(Categorical DQN 51): Q-값의 분포를 학습하는 DQN 확장
[3.1.09] IQN(Implicit Quantile Networks): Q-값의 분포를 세밀하게 조정하는 방식
[3.1.10] Rainbow: 여러 DQN 확장(PER, Double DQN, C51 등)을 결합한 통합 알고리즘
[3.1.11] SQL(Soft Q-Learning): 엔트로피를 추가하여 Q값 학습을 안정화하는 방식
[3.1.12] PER(Prioritized Experience Replay): 중요한 경험을 우선적으로 학습하는 경험 리플레이 전략
[3.1.13] HER(Hindsight Experience Replay): 목표 달성을 학습할 수 있도록 과거 경험을 재사용
[3.1.14] NoisyNet: 신경망 가중치에 노이즈를 추가해 탐색 효율성을 높이는 방식

[3.2] Model-free RL : Policy based methods
[3.2.01] REINFORCE: 정책 경사법의 기본 형태
[3.2.02] Actor-Critic: 기본적인 Actor-Critic 구조, Policy Gradient와 Critic의 Q값 평가 결합
[3.2.03] NAC(Natural Actor-Critic): Natural Gradient를 적용해 정책의 효율적 업데이트를 수행
[3.2.04] A2C/A3C(Advantage Actor-Critic): 분산형 Actor-Critic 모델
[3.2.05] ACER(Actor-Critic with Experience Replay): 경험 리플레이를 추가한 Actor-Critic 방법
[3.2.06] IMPALA(Importance Weighted Actor-Learner Architecture): 분산 학습에 최적화된 구조
[3.2.07] Off-PAC(Off-Policy Actor-Critic): 오프폴리시 데이터를 활용하는 Actor-Critic 기법
[3.2.08] PPO(Proximal Policy Optimization): 신뢰 구간을 사용해 안정적으로 정책을 업데이트
[3.2.09] TRPO(Trust Region Policy Optimization): 정책 급변을 방지하는 최적화 기법
[3.2.10] DDPG(Deep Deterministic Policy Gradient): 연속적 행동 공간에서 학습
[3.2.11] TD3(Twin Delayed DDPG): DDPG의 한계점을 극복하기 위한 개선된 모델
[3.2.12] SAC(Soft Actor-Critic): 탐색과 활용의 균형을 유지하도록 설계된 정책 학습 모델
[3.2.13] BC(Behavioral Cloning): 데이터를 기반으로 정책을 모방하는 방식
[3.2.14] DDPGfD(DDPG from Demonstrations): 전문가의 시범을 사용해 DDPG 성능을 개선

[3.3] Model-based RL : Given the Model
[3.3.01] Dyna-Q: 모델 기반 RL과 모델-프리 RL을 조합한 알고리즘
[3.3.02] AlphaZero: 시뮬레이션을 통한 최적의 행동을 찾는 Monte Carlo Tree Search 기반 모델

[3.4] Model-based RL : Learn the Model
[3.4.01] World Models: 환경을 모델링하고 시뮬레이션을 통해 학습
[3.4.02] I2A(Imagination-Augmented Agents): 상상된 상태에서 정책을 훈련
[3.4.03] MBMF(Model-Based Model-Free): 모델기반 접근과 모델-프리 접근을 혼합
[3.4.04] MBVE(Model-Based Value Expansion): 모델을 학습 보조수단으로 에이전트가 환경에서 수집한 데이터로 학습
[3.4.05] Dreamer: 에이전트가 환경 데이터를 수집하여 모델을 학습하고 이를 활용해 정책과 가치 함수를 학습
[3.4.06] PlaNet: Dreamer의 전신
[3.4.07] PETs(Probabilistic Ensembles with Trajectory Sampling): 확률적 모델 앙상블을 활용
[3.4.08] MuZero: 알파고(AlphaGo) 시리즈의 발전된 형태(명시적 환경 모델 없이도 정책과 가치를 학습)

[4.2] 배깅(Bagging)
[4.3] 부스팅(Boosting) :  AdaBoost, Gradient Boosting, XGBoost, LightGBM, CatBoost
